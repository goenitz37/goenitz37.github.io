Privacy Policy

Application: Stock Research Drive Sync. Last updated: 10 October 2026.

Stock Research Drive Sync (the "Application") is a personal automation used only by its developer, for the developer's own stock market research. It is not offered to the public and no other person is expected to sign in to it.

Data the Application accesses

  • Google Drive: stock price CSV files and one small sync-state file inside the developer's own Google Drive folders. The Application can read and write those files.
  • Google Sheets: read-only access to one spreadsheet owned by the developer that lists the stock symbols to track.
  • Google account sign-in token: an OAuth refresh token for the developer's own account.

How the data is used

The data is used only to keep the developer's own stock price files up to date. The Application does not use Google user data for advertising, profiling, or any purpose unrelated to that function.

Storage and security

The OAuth refresh token is stored only as an encrypted secret in the developer's own private GitHub Actions settings. It is never published in code, logs, or public pages. Price files stay in the developer's own Google Drive.

Sharing and disclosure

The Application does not sell, rent, transfer, or share Google user data with any third party. No human other than the developer reads the data. Public stock price data is fetched from a market-data provider; no Google user data is sent to that provider.

Google API Services User Data Policy

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention, revocation and deletion

Files stay in the developer's Drive until the developer deletes them. The developer can revoke the Application's access at any time at myaccount.google.com/permissions and can delete the stored secret in GitHub at any time.
